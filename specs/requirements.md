# Krav & önskemål

## Mål
- Skapa en statisk resesida för att samla och jämföra resmål.
- Dela enkelt med resebyrå för prisförslag.

## Funktionella krav
- **Landningssida** med val av resmål.
- **Resmålssidor** med egna datafiler.
- **Spec-sidor** för krav och tekniska val.
- Allt är statiskt och uppdateras via kodändringar.

## Innehåll och data
- All data lagras i statiska filer under `trips/`.
- Mall ska kunna återanvändas för nya resmål.

## Design
- Responsiv layout för mobil och desktop.
- Enkel och lättläst.

## Publicering
- Automatiskt via GitHub Pages vid push till `master`.
